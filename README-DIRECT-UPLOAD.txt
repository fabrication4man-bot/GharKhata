Ghar Khata — READY TO UPLOAD FILES

इस ZIP में चार तैयार फाइलें हैं: index.html, final-update.js, family-money.js, sw.js.

मोबाइल से GitHub पर अपलोड करने का तरीका:
1) सबसे पहले Ghar Khata खोलकर Settings > Backup & restore > Download backup से बैकअप डाउनलोड करें।
2) ZIP फोन में डाउनलोड करके Extract करें।
3) GitHub repository fabrication4man-bot/GharKhata खोलें।
4) Add file > Upload files चुनें। Extract की हुई चारों फाइलें चुनें।
5) GitHub जब existing files के replacement की पुष्टि करे, तब इन्हीं चार फाइलों को overwrite/replace करें और Commit changes दबाएँ।
6) Website खोलें: https://fabrication4man-bot.github.io/GharKhata/?v=7
7) टेस्ट करें: हिंदी/English, grocery units, photo/file import, back navigation, और “घर के लिए रकम” फीचर।
