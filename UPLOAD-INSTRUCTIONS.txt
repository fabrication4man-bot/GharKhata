GharKhata grocery-list fixes

BEFORE UPLOADING:
1. In GitHub, download a ZIP backup of the current repository.
2. Keep an in-app JSON backup of your records from GharKhata > Backup & restore.
3. Extract this ZIP on your phone.
4. Upload/replace the files INSIDE the GharKhata-Fix folder at the repository root (do not upload the folder itself).
5. Commit the changes.
6. Open the live site in Chrome and refresh. If the old version remains, close the app fully and reopen the site in a fresh tab.

Included fixes:
- Add extra grocery rows beyond the default 50 rows.
- Auto-save grocery edits; explicit Save button remains available.
- Grocery screen, units, buttons, PDF labels and CSV headers switch between Hindi and English.
- Mobile grocery table stays inside its own horizontal scroll area.
- Print/PDF layout includes GharKhata name, month, populated rows only, and app QR code.

PDF NOTE:
On Android, tap “Download PDF / Print” and choose “Save as PDF” in the print dialog. This browser print flow is used instead of a server-generated PDF.

This ZIP has not been fully device-tested. Test with a small sample list first and confirm the PDF QR opens https://fabrication4man-bot.github.io/GharKhata/ before relying on it.
